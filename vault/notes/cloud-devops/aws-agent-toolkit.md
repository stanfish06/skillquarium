# aws-agent-toolkit

> [!info] What it does
> Pull AWS's official agent skills (Agent Toolkit for AWS, ~115 skills) from the remote catalog on demand with the `aws agent-toolkit` CLI instead of keeping them installed. Use for any task on a specific AWS service — DynamoDB, Aurora/RDS, Lambda, Step Functions, API Gateway, CDK, CloudFormation, IAM, VPC/Route 53/CloudFront/WAF, S3, EFS, CloudWatch, Glue/Athena/MWAA/MSK/Redshift, Bedrock, Braket, Amplify — or when the user mentions `aws configure agent-toolkit`, the AWS MCP Server, or wants AWS skills installed.
