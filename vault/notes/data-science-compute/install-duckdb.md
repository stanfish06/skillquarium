# install-duckdb

> [!info] What it does
> Install or update DuckDB extensions. Each argument is either a plain extension name (installs from core) or name@repo (e.g. magic@community). Pass --update to update extensions instead of installing. Also checks that the DuckDB CLI is present and, if it is not, suggests how to install it, system-wide or in a Python virtual environment.
