# mermaid-studio

> [!info] What it does
> Validate and render Mermaid diagrams to SVG, PNG, or ASCII with bundled scripts (mermaid-cli, beautiful-mermaid, Puppeteer icon packs), plus styling rules for C4 and AWS architecture-beta diagrams. Use when a .mmd file needs a syntax check, a rendered image, batch rendering, ASCII output, an AWS icon diagram, a C4 diagram, or one of the 20 bundled themes. Do not use for choosing a diagram type or writing Mermaid inside markdown docs (use markdown-mermaid-writing or diagram-generator), or for previewing in the terminal (use mermaid-terminal).
