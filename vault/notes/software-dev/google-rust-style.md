# google-rust-style

> [!info] What it does
> Use when writing, reviewing, or refactoring Rust code — module layout and imports, function parameter and return types (&str vs &String, slice vs &Vec, iterators, bool flags), traits and derives, Option/Result/panic, naming, doc comments, unsafe, unwrap/expect, iterator chains — or when the user asks for Google's Rust style guide, or works in Chromium, Android, or Fuchsia Rust. For the rust-coding-guidelines rule IDs (P.NAM, G.FMT, ...) use coding-guidelines instead.
