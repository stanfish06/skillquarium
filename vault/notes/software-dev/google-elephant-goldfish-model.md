# google-elephant-goldfish-model

> [!info] What it does
> Pointer to Google's Elephant-Goldfish Model (EGM) plugin, installed as a Claude Code or Codex plugin rather than copied into this vault. EGM drafts software design specs with full project context (Elephant) and reviews them with fresh-context subagents that never saw the conversation (Goldfish). Use when the user wants to brainstorm a feature into a design doc, draft a spec section by section, run a fresh-eyes review of a design doc, README, or PR plan against the code, check docs for drift from the code, bootstrap directory READMEs, or mentions EGM, egm-review, or elephant-goldfish.
